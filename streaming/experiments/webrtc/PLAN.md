# WebRTC proof of concept

1. Test Windows Graphics Capture capability and encoder support.
2. Choose standards-based secure peer signaling and ICE (no custom crypto).
3. Test Android decode/render under PLEOS approved app window.
4. Confirm track pause/teardown and black screen during unsafe state.
5. Measure latency, FPS, hardware CPU/GPU and network recovery.
6. Only then propose Windows Host and Android client integration.
