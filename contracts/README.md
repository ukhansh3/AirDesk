# Canonical contract directory

- gesture/gesture-event.schema.json — pointer visual diagnostics, pinch/drag, tracking lost.
- control/messages.schema.json — debug authentication/connection status.
- input/input-event.schema.json — reserved remote OS input, NOT enabled.
- session/session-state.schema.json — UI state projection.
No automatic generation of REST endpoints or streaming video over JSON.
Validate against JSON Schema 2020-12. New event types and incompatible changes require migration review.
